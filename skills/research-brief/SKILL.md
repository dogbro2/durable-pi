# 投研資料摘要

## 何時使用

出現以下任一情況時使用本技能：

- 使用者給出多份研報、公告、財報、訪談或新聞，要求提煉要點。
- 需要圍繞一個公司、行業或主題做資料綜述。
- 需要區分「資料原文」「分析推斷」「個人觀點」。
- 需要把長報告壓縮成一頁決策摘要。

不適用：替使用者做買賣決策、給出目標價、或把沒有來源的猜測寫成事實。

## 輸入

必需：

- 研究問題：要看什麼、為什麼看、最終要支援什麼判斷。
- 資料來源：使用者提供的檔案、連結或正文。

可選：

- 時間範圍：只看最近一個季度、一年或特定日期之後。
- 關注維度：收入、利潤、份額、政策、競爭、估值。
- 讀者：投資團隊、業務負責人、客戶。
- 期望結論形式：一頁摘要、對比表、風險清單。

資料來源不足時，明確列出缺口；不要用常識補成事實。

## 輸出原則

1. **結論先行**：開頭三句話給出最重要的發現和不確定性。
2. **每個數字有出處**：標明資料名稱、日期和口徑。
3. **事實與推斷分欄**：推斷必須寫依據和假設。
4. **正反證據都保留**：不能只挑支援結論的材料。
5. **口徑一致**：跨資料比較時統一幣種、週期和統計範圍。
6. **未知顯式化**：沒有資料就說沒有，不用模糊詞掩蓋。

## 工作流程

1. **定義問題**：把研究問題改寫成 2–4 個可回答的子問題。
2. **盤點資料**：列出每份資料的來源、日期、型別和可信度；標記一手資料與二手解讀。
3. **抽取事實**：逐份提取數字、時間、主體和條件，保留原文口徑。
4. **交叉驗證**：同一事實至少找兩個來源；衝突時並列呈現並說明差異。
5. **形成判斷**：每條判斷寫成「結論 + 證據 + 假設 + 反證」。
6. **識別風險**：列出會推翻結論的關鍵變數和觀察指標。
7. **壓縮結構**：按「結論—證據—分歧—未知—跟蹤項」組織。
8. **自檢**：核對每個數字能否回到來源，每個判斷是否超出資料範圍。

## 證據分級

- **A 級**：監管披露、公司公告、經審計財報、原始資料。
- **B 級**：公司交流紀要、行業協會資料、可信媒體的一手報道。
- **C 級**：券商研報的預測、專家訪談的轉述、二手解讀。
- **D 級**：社交媒體、匿名訊息、無法核實的傳聞。

結論主要依賴 A/B 級證據；使用 C 級時標註「預測」；D 級只作為線索，不進入核心結論。

## 對比研究規則

- 對比公司時統一會計期間、幣種和調整口徑。
- 市佔率說明分母是出貨量、收入還是使用者數。
- 增速說明是同比、環比還是複合增速。
- 估值指標說明是靜態、動態還是前瞻，並寫明預測來源。
- 政策影響說明生效時間、適用範圍和過渡期。

## 處理衝突資料

1. 先確認是否是同一口徑；口徑不同則分別列示，不強行合併。
2. 口徑相同但數字衝突時，優先採用更接近一手披露的資料。
3. 仍無法判斷時，在正文並列兩個數字，並寫「待核」。
4. 不因為某份資料更長、更新或語氣更確定就預設它正確。

## 質量檢查清單

- [ ] 開頭結論能在 30 秒內讀完。
- [ ] 每個關鍵數字都有來源和口徑。
- [ ] 事實、推斷、觀點沒有混寫。
- [ ] 至少列出兩條反方證據或風險。
- [ ] 資料缺口和未知項明確。
- [ ] 跟蹤指標可觀察、可觸發動作。
- [ ] 沒有目標價、買賣建議或無依據的預測。

## 邊界

- 本技能只做資料整理和分析輔助，不構成投資建議。
- 不篡改原始資料，不把預測值寫成實際值。
- 不引用無法核實的內部訊息作為核心證據。
- 涉及未公開資訊時，提示使用者遵守合規要求並停止展開。
