# 客服 / 商務回覆潤色

## 何時使用

出現以下任一情況時使用本技能：

- 使用者給出一段回覆草稿，要求改得更專業、更有禮貌或更簡短。
- 需要回復客戶投訴、延期說明、報價詢問或合作邀約。
- 需要把內部討論轉成對外郵件或即時訊息。
- 需要同一事實的不同語氣版本：正式郵件、即時訊息、安撫回覆。

不適用：替使用者承認未確認的責任、承諾賠償、或改寫法律條款。

## 輸入

必需：

- 原始草稿或要點。
- 回覆物件：客戶、合作方、同事、上級。
- 溝通目標：告知、道歉、拒絕、催辦、報價、確認。

可選：

- 渠道：郵件、即時訊息、工單、公開評論。
- 語氣：正式、友好、剋制、堅定。
- 不能承諾的邊界：時間、金額、責任。
- 品牌稱呼、署名和格式要求。
- 希望對方採取的下一步。

缺失關鍵事即時先問；不能問時用「待確認」佔位，不自行補承諾。

## 潤色原則

1. **先回應，再解釋**：第一段直接回應對方最關心的事。
2. **事實準確**：不改數字、日期、責任歸屬和已確認的方案。
3. **承諾有邊界**：只寫已確認能做的事；不確定的寫「確認後回覆」。
4. **結構清楚**：一段一個目的，長回覆用小標題或短列表。
5. **語氣穩定**：不卑不亢，不用過度道歉，也不用強硬措辭。
6. **下一步明確**：誰在什麼時候做什麼，寫清楚。
7. **刪掉空話**：刪除「非常抱歉給您帶來不便」之類的套話堆疊，保留一次真誠回應。

## 工作流程

1. **識別真實訴求**：對方是在要答案、要補償、要時間，還是要情緒安撫。
2. **核對事實**：把草稿中的數字、日期、承諾和責任人逐項對照輸入。
3. **標記風險句**：找出可能構成承諾、歸責或法律含義的句子。
4. **重排結構**：按「回應—說明—方案—下一步」重寫。
5. **調整語氣**：根據物件和渠道選擇正式度；對外比對內更剋制。
6. **壓縮**：刪除重複道歉、形容詞和無關背景。
7. **輸出對照**：給出潤色稿、修改說明和需要使用者確認的風險點。
8. **自檢**：確認沒有新增事實、沒有擴大承諾、沒有改變立場。

```markdown

- <改動一>：<為什麼這樣改。>
- <改動二>：<...>

## 需要確認

- <風險句或缺失資訊>：<建議如何確認。>

## 可選版本（如需要）

### 更簡短

<壓縮版。>

### 更正式

<正式版。>
```

## 常見場景模板

### 客戶投訴

```text
您好，<稱呼>：

關於您反饋的 <問題>，我們已確認 <事實>。給您帶來的影響，我們表示歉意。

當前處理方案是 <已確認的動作>，預計 <時間> 完成。若 <條件>，我們會 <後續動作>。

下一步需要您 <配合事項>。如有疑問，可直接回複本訊息。
```

### 延期說明

```text
您好，<稱呼>：

原定 <日期> 交付的 <事項> 需要調整到 <新日期>。原因是 <已確認原因>，不是 <排除項>。

為減少影響，我們已 <補救動作>。新的交付範圍是 <範圍>，驗收方式是 <方式>。

如這個時間影響您的安排，請在 <時間> 前告知，我們再評估替代方案。
```

### 拒絕請求

```text
您好，<稱呼>：

感謝您提出 <請求>。經評估，我們目前無法按 <原方案> 推進，主要限制是 <客觀原因>。

可以替代的方案是 <方案 A> 或 <方案 B>，各自的條件是 <條件>。

如果您希望推進，請確認優先方案，我們再給出具體排期。
```

### 報價詢問

```text
您好，<稱呼>：

根據您提供的 <需求範圍>，初步報價為 <金額/區間>，包含 <交付項>，不含 <排除項>。

報價有效期至 <日期>。最終價格以 <確認條件> 為準。

如範圍有變化，請補充 <資訊>，我們會在 <時間> 內更新報價。
```

### 催辦

```text
您好，<稱呼>：

想確認 <事項> 的進展。該專案原計劃 <日期> 完成，目前我們這邊需要 <依賴項> 才能繼續。

請在 <時間> 前回復 <具體資訊>。如果時間需要調整，也請告知新的預期，方便我們同步相關方。
```

## 語氣規則

- **正式郵件**：完整稱呼、分段、結論在前、署名完整。
- **即時訊息**：三到五句，先說要緊事，避免長段落。
- **公開評論**：不披露內部資訊，不爭論，引導到私下渠道。
- **安撫場景**：先承認影響，再給事實和方案；不重複空洞道歉。
- **強勢場景**：用事實和邊界表達堅定，不用威脅性措辭。

## 風險句檢查

以下句子必須經過使用者確認後才能保留：

- 明確的時間承諾：「我們會在週五前完成」。
- 金額或補償：「退還全部費用」「贈送一個月」。
- 責任歸屬：「是我們的失誤」「與貴方無關」。
- 排他或獨家表述：「只為您保留」「不再向其他客戶提供」。
- 法律含義：「雙方達成一致」「最終解釋權」。
- 資料披露：客戶名稱、合同金額、內部指標。

無法確認時改寫為：「我們會在確認後第一時間回覆具體時間」「補償方案需要按合同條款評估」。

## 質量檢查清單

- [ ] 第一段回應了對方最關心的問題。
- [ ] 數字、日期、責任和方案與原稿一致。
- [ ] 沒有新增未確認的承諾。
- [ ] 每段只有一個目的。
- [ ] 下一步有物件、動作和時間。
- [ ] 語氣與物件、渠道匹配。
- [ ] 刪除了重複道歉和空泛套話。
- [ ] 風險句已單獨列出等待確認。

## 邊界

- 不替使用者做法律、賠償或合同解釋。
- 不偽造已完成的處理動作。
- 不把客戶投訴改寫成對抗性表達。
- 涉及監管、訴訟、退款爭議時，提示轉交對應負責人。
